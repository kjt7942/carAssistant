처음 한 번만 연결하면 됩니다

루틴·정비 내역·메모는 내 깃허브의 비공개 저장소에만 저장됩니다. 이 페이지에는 아무것도 저장되지 않고, 토큰은 이 폰 브라우저 안에만 보관됩니다.

  1. 비공개 저장소 만들기 — 이름 carAssistant-data, Private 선택 후 Create.
  2. 토큰 만들기 — Repository access: Only select repositories → carAssistant-data, Permissions → Repository permissions → Contents: Read and write. 만료일은 길게(예: 1년).
  3. 만들어진 토큰(github_pat_…)을 복사해 아래에 붙여 넣습니다.

말 한마디로 여러 동작을 차례로 실행합니다.

차에서 "메모 ○○○"라고 말한 내용도 여기에 나타납니다.

차에 연결

차 화면의 옵션 → 폰 연동 → 연동 설정 → 폰으로 연결을 누르면 주소가 나옵니다. 폰을 차와 같은 와이파이(핫스팟)에 연결한 뒤, 그 주소를 아래에 입력하세요. 토큰이 차로 전달됩니다.
