# carAssistant

안드로이드 헤드유닛(차량 기기)용 시계·날씨·음성 비서 앱입니다.

- 시계·날짜·요일을 큰 글씨로 표시합니다 (야간 운전용 다크 화면).
- GPS로 현재 위치를 읽고, 그 위치의 날씨를 자동으로 갱신합니다 (Open-Meteo, 키 불필요).
- 화면의 `음성 명령` 버튼으로 한국어 음성 명령을 합니다 (날씨, 시간, 날짜, 밝기, 24시간 표시).
- `진단` 버튼으로 이 기기에서 GPS, 마이크, 음성 인식, 음성 출력이 되는지 확인합니다.

대상: Android 10 (API 29) 이상. 구글 플레이 서비스가 없어도 GPS는 동작하도록 안드로이드 기본 위치 기능만 사용합니다.

## 설치

1. 저장소의 [Releases](../../releases/tag/latest)에서 `carAssistant.apk`를 내려받습니다.
2. 기기에서 파일을 열어 설치합니다. 처음에는 "출처를 알 수 없는 앱 설치" 허용이 필요할 수 있습니다.
3. 앱을 열고 위치와 마이크 권한을 허용합니다.

## 빌드

`main`에 올리면 GitHub Actions가 디버그 APK를 만들어 `latest` 릴리스에 올립니다.

## 구조

- `app/src/main/assets/index.html`: 화면과 음성 명령 처리
- `app/src/main/java/com/kjt7942/carassistant/MainActivity.kt`: GPS, 음성 인식, 음성 출력을 화면에 연결

## 알려진 한계

- 음성 인식은 기기에 설치된 안드로이드 음성 인식 서비스(보통 구글 앱)를 사용합니다. 없으면 진단 화면에 "서비스 없음"으로 나옵니다.
- 음성 출력(TTS)은 기기에 한국어 TTS 엔진이 있어야 합니다. 없으면 답변이 화면에만 표시됩니다.
- 자유 대화(Claude 연결)는 아직 없습니다.

## 자동 업데이트

- **화면(index.html) 변경**: 앱이 6시간마다(및 시작 시) `version.json`을 확인해 새 화면을 조용히 내려받아 바로 적용합니다. 새 화면이 15초 안에 정상 시작하지 못하면 내장 화면으로 자동 복귀합니다.
- **앱(네이티브) 변경**: 새 APK를 자동으로 내려받고, 화면 상단에 `지금 설치` 버튼이 나옵니다. Android 10은 설치 확인 탭 1회가 필요합니다.
- 네이티브 코드/매니페스트/gradle을 바꿀 때만 `native-version.txt`를 1 올립니다.
- 업데이트 설치에는 항상 같은 서명 키가 필요합니다. 저장소 Secrets에 `KEYSTORE_B64`, `KEYSTORE_PASSWORD`를 등록하세요. 없으면 APK 업데이트는 알리지 않고 화면 업데이트만 나갑니다.
- 처음 한 번은 기존 앱을 삭제하고 새 서명 키로 빌드된 APK를 설치해야 합니다. 설치 후 '출처를 알 수 없는 앱 설치'를 허용해 주세요.
